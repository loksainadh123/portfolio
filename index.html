Stock Market ETL & forecasting pipeline

Data infrastructure for 172 stock symbols. Live Alpha Vantage data and historical files from AWS S3 flow through scheduled Airflow workflows into a MySQL star schema, then into forecasts and a dashboard.

  • Scheduled Apache Airflow DAGs with retries combine the live API and S3 historical sources.
  • Designed a MySQL star schema: 1 fact table, 2 dimension tables and 1 reporting view.
  • 42,000+ rows pass 7 automated quality checks, and idempotent upserts keep it at zero duplicates across repeated runs.
  • Time-series forecasting shown in a Streamlit + Plotly dashboard.
  • Python
